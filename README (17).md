# EXPERIMENT 6 — Responsive Blog Website

**Student:** Daksh Kasana  
**Subject:** JCS 308 | Web Designing Lab

## Objective
Build a responsive blog website using media queries and Bootstrap.

## Aim
To create a responsive blog website that adapts its layout to mobile, tablet, and desktop screen sizes using CSS media queries and Bootstrap.

## Description
Responsive web design ensures that content remains usable on different screen sizes. CSS media queries apply styles according to viewport conditions. Bootstrap provides a responsive grid system and reusable components such as navigation bars, cards, and buttons. A mobile-first layout starts with small screens and progressively enhances the design for larger screens.

## Software Required
VS Code and Google Chrome (internet connection required for Bootstrap CDN).

## Source Code Files
- `index.html` — Bootstrap blog layout
- `style.css` — card and media-query styles

## Output
A responsive blog webpage with a navigation bar, three article cards, and a footer. The layout adjusts for smaller screens.
