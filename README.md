# EXPERIMENT 1 — GitHub Repository, Branches, Merge and GitHub Pages

**Student:** Daksh Kasana  
**Subject:** JCS 308 | Web Designing Lab

## Objective
Set up a GitHub repository, branches, merge changes, and host a static website using GitHub Pages.

## Aim
To practise version control using Git and GitHub by creating a repository, managing branches, merging changes, and publishing a static website.

## Description
Git is a distributed version-control system used to track changes in source code. GitHub hosts Git repositories and supports collaboration. Branches allow developers to work independently; merging combines completed work. GitHub Pages publishes static HTML, CSS, and JavaScript files as a website.

## Software Required
VS Code, Git and GitHub, GitHub Desktop, HTML and CSS, GitHub Pages, Google Chrome.

## Source Code Files
- `index.html` — webpage
- `style.css` — styling

## Output
A GitHub repository containing the website source files, a merged feature branch, and a publicly accessible GitHub Pages URL.

## Live Website URL
`https://YOUR-GITHUB-USERNAME.github.io/Webd-exp-1/` *(replace after publishing your own repository)*

## GitHub Repository URL
`https://github.com/YOUR-GITHUB-USERNAME/Webd-exp-1` *(replace after creating your own repository)*

## Conclusion
In this experiment, I created a GitHub repository and uploaded a simple webpage made with HTML and CSS. I made a new branch, changed the code in it and merged it back into the main branch. Then I used GitHub Pages to publish the webpage. I learned how version control works and how Git and GitHub help to manage a project and to work with other people.
