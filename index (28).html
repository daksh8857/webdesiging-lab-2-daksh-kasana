User Authentication

Experiment 9 — Node.js, Express.js, MongoDB, bcrypt and JSON Web Token.

The working registration and login interface is in public/index.html. It requires the Express backend and MongoDB to be running.

Run the application

  1. Copy .env.example to .env and configure MongoDB URI and JWT secret.
  2. Run npm install.
  3. Run npm start.
  4. Open http://localhost:3000.

GitHub Pages cannot run the Node.js server or MongoDB backend.
