# EXPERIMENT 3 — Dynamic To-Do List

**Student:** Daksh Kasana  
**Subject:** JCS 308 | Web Designing Lab

## Objective
Create a dynamic To-Do List application using JavaScript and DOM manipulation.

## Aim
To develop an interactive To-Do List that allows users to add, delete, and mark tasks as completed using JavaScript.

## Description
The Document Object Model (DOM) represents an HTML page as a tree of objects. JavaScript can select elements, create new elements, change text or classes, and respond to user events. An event listener handles actions such as clicking an Add or Delete button. The application maintains the task list in the page DOM, following the sample implementation.

## Software Required
VS Code and a modern web browser.

## Source Code Files
- `index.html` — task input and list
- `style.css` — layout and completed-task style
- `script.js` — add, complete and delete actions

## Output
A To-Do List webpage where a user can add tasks, mark them as completed by clicking the task text, and delete them.
