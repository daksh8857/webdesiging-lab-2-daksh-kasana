## Important hosting note
GitHub Pages and Netlify static hosting can publish static HTML/CSS/JS previews. They do not run Node.js servers or MongoDB. Experiments 8, 9, 10 dynamic-app and 12 require a Node.js host and, where applicable, a MongoDB connection. The source files are included; no cloud deployment is claimed.
