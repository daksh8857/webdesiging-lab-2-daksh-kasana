**Student:** Daksh Kasana  
**Subject:** JCS 308 | Web Designing Lab

## Objective
Develop a single-page React application for managing notes (CRUD operations).

## Aim
To develop a React single-page application that allows users to create, view, update, and delete notes.

## Description
React is a JavaScript library for building component-based user interfaces. Components divide an application into reusable parts. State stores data that can change over time; useState is commonly used for local component state. CRUD refers to Create, Read, Update, and Delete operations. React rerenders the interface when state changes.

## Software Required
Node.js, VS Code, and a web browser.

## Source Code Files
- `src/App.jsx` — notes CRUD component
- `src/App.css` — styling
- `src/main.jsx` — React entry point
- `index.html`, `package.json`, `vite.config.js` — Vite setup

## Output
A React single-page application where users can add, view, update, and delete notes.
