Book Collection REST API

Node.js · Express.js · JSON

This experiment runs as a local Node.js server. Start the server, then test the routes below in a browser or Postman.

  • GET /books — display all books
  • GET /books/:id — display one book
  • POST /books — add a book
  • PUT /books/:id — update a book
  • DELETE /books/:id — remove a book

Initial data: Wings of Fire and The Alchemist.

npm install
npm start
