# GitHub workflow for Experiment 1
1. Create a public repository named `Webd-exp-1`.
2. Upload `index.html` and `style.css`.
3. Create a branch named `feature-about`.
4. Edit the About section on that branch and commit the change.
5. Open a pull request and merge it into `main`.
6. In Settings → Pages, choose Deploy from a branch → `main` → `/ (root)`.
7. Wait for GitHub Pages to publish the site and then copy your own URL into the record.
