## Objective
Optimize a webpage for SEO and accessibility using semantic HTML, heading structure, and meta tags.

## Aim
To improve the search-engine visibility and accessibility of a webpage by applying semantic HTML, meaningful headings, metadata, and accessible attributes.

## Description
Search Engine Optimization (SEO) helps search engines understand webpage content. Semantic HTML gives meaning to page regions. A logical heading hierarchy helps users and assistive technologies understand content structure. The objective and meta description summarize a page in search results. Accessibility practices include descriptive alt text, labels for form controls, keyboard navigation, and sufficient color contrast.

## Software Required
VS Code and Google Chrome (or any modern web browser).

## Source Code Files
- `index.html` — semantic webpage and metadata
- `style.css` — basic presentation
- `web-design.svg` — illustrative image with alt text

## Output
A webpage using semantic elements, a logical heading hierarchy, descriptive meta tags, navigation, and accessible form labels and image text.
