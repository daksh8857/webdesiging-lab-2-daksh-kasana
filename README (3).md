## Objective
Develop a personal portfolio webpage using HTML and CSS.

## Aim
To design a personal portfolio webpage that presents personal information, skills, projects, and contact details using HTML and CSS.

- `style.css` — form styling
- `script.js` — submit confirmation

## Output
A styled personal portfolio form with personal details, an education qualification table, selected course and declaration, matching the supplied sample output.
