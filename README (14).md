# EXPERIMENT 5 — Weather Application

**Student:** Daksh Kasana  
**Subject:** JCS 308 | Web Designing Lab

## Objective
Create a weather application using Fetch API or Axios.

## Aim
To build a weather application that accepts a city name and displays current weather information retrieved from a weather API.

## Description
A web API allows an application to request data from a remote service. The Fetch API provides a JavaScript interface for making HTTP requests and returns a Promise. The response is commonly converted to JSON. This weather application uses Open-Meteo geocoding to find coordinates and its forecast API to retrieve temperature, humidity and wind speed. No API key is required for this demonstration.

## Software Required
VS Code and a modern web browser with an internet connection.

## Source Code Files
- `index.html` — weather interface
- `style.css` — weather card styling
- `script.js` — Fetch API requests

## Output
The application displays the selected city's current temperature, humidity, and wind speed.
