## Objective
Optimize a website using caching, CSS/JS minification, and lazy loading of images.

## Aim
To improve website loading performance by applying browser caching, minification of CSS and JavaScript, and lazy loading of images.

## Description
Web performance optimization reduces download size and improves perceived loading speed. Minification removes unnecessary whitespace and comments from CSS and JavaScript. Browser caching allows reusable resources to be stored locally according to HTTP cache headers. Lazy loading delays loading off-screen images until they are near the viewport. Performance should be measured before and after changes using browser developer tools or Lighthouse.

## Software Required
VS Code, Google Chrome, and a local web server or hosting platform.

## Source Code Files
- `index.html` — optimized gallery and lazy-loading attributes
- `style.css` / `style.min.css` — normal and minified CSS
- `script.js` / `script.min.js` — normal and minified JavaScript
- `.htaccess-example.txt` — Apache caching rules
- `photo1.svg`, `photo2.svg`, `photo3.svg` — local gallery images

## Output
A webpage that uses minified CSS and JavaScript, lazy-loaded images, and an example of browser caching configuration.
